# 기말고사 시간표 조회

**반(1~6)을 고르고 번호를 입력**하면 그 학생이 **응시하는 시험 과목과 시험실**을 시간표로 정리해 주는 정적 웹페이지입니다.
이미지로 저장하거나 인쇄(PDF)할 수 있습니다.

> 2026학년도 1학기 기말고사 · 나주고등학교 3학년 기준

## 사용법

`index.html` 을 열면 **반 선택 화면**이 나옵니다. 반을 고른 뒤, 학번 앞 두 자리(예: `32`)는 고정이므로 **뒤 번호만** 입력합니다.

- **이미지 저장**: 시간표 카드를 PNG 파일로 내려받기
- **인쇄 / PDF**: 브라우저 인쇄 기능으로 출력 또는 PDF 저장

### 반별 주소 (배부용)

각 반은 **무작위 토큰** 주소를 씁니다. 링크만 보고는 몇 반인지 알 수 없고,
토큰을 바꿔 다른 반에 접근할 수도 없습니다. 반 학생들에게 해당 링크를 나눠 주세요.

| 반 | 주소 |
|----|------|
| 반 선택(허브) | `…/najuhighexam/` |
| 1반 | `…/najuhighexam/?k=566f8cb7` |
| 2반 | `…/najuhighexam/?k=f980d51e` |
| 3반 | `…/najuhighexam/?k=1fe051a1` |
| 4반 | `…/najuhighexam/?k=041ce67a` |
| 5반 | `…/najuhighexam/?k=4f428556` |
| 6반 | `…/najuhighexam/?k=85f010ac` |

- 특정 학생 바로 열기: `?k=f980d51e&num=5`
- 배포 주소: `https://maechorom31-pixel.github.io/najuhighexam/`
- `?k=` 토큰이 없거나 잘못되면 어떤 반도 열리지 않고 **반 선택 화면**이 표시됩니다.

> **참고(정적 사이트 한계)**: 토큰↔반 매핑은 `index.html`/허브 화면에 들어 있어
> 소스를 열어보면 확인은 가능합니다. 즉 "링크만으로는 추측 불가"이지만 완전한 비공개는 아닙니다.
> 매핑이 드러나는 게 싫으면 **허브(루트 주소)는 공유하지 말고** 반별 토큰 링크만 배부하세요.

## 구성

| 파일 | 설명 |
|------|------|
| `index.html` | 반 선택 + 번호 입력 + 개인 시간표 렌더 |
| `schedule.js` | 기말고사 시간표 + 과목 분류(일반선택/진로선택) |
| `data/<토큰>.js` (6개) | 반별 데이터: 학번별 `{교시: [과목, 시험실]}` — 파일명도 무작위 토큰, **Base64 인코딩**, 이름 없이 학번만 |

> 과목·시험실은 학교 **시험실 배치표(좌석표)** 기준으로 생성합니다. 표에 보이지 않는 시간은 자율학습이며,
> 자습실이 따로 배정된 경우(📍)와 각 반 교실에서 자습하는 경우를 구분해 표시합니다.

해당 반 주소로 들어올 때 **그 반의 데이터 파일만** 로드됩니다.

## 데이터 규칙

- **공통 과목**(화법과 작문, 영어독해와 작문)은 전체 학생이 응시합니다.
- **선택 과목**은 수강한 경우에만 응시하고, 아니면 그 시간은 **자율학습**(시험 없음)입니다.
- 배지는 교육과정 분류를 따릅니다.
  - **일반선택**: 화법과 작문, 영어독해와 작문, 미적분, 윤리와 사상, 한국지리, 사회문화
  - **진로선택**: 경제수학, 기하, 수학과제 탐구, 심화국어, 영미 문학 읽기, 화학Ⅱ, 생명과학Ⅱ, 물리Ⅱ, 지구과학Ⅱ, 일본어2, 프로그래밍
- 지필고사가 없는 선택과목(사회문제탐구·생활과 과학·교육학·논술·보건 등)은 시간표에서 제외했습니다.

## 데이터 / 개인정보

- 명단은 **이름 없이 학번만** 사용하며, `data/cN.js` 에 **Base64로 인코딩**되어 평문 노출을 줄였습니다.
  (정적 페이지 특성상 완전한 비공개는 아니며, 한 번의 복호화 경로를 거쳐 로드됩니다.)
- 시간표가 바뀌면 `schedule.js`, 명단이 바뀌면 해당 반 `data/cN.js` 를 갱신하세요.

## 캐시 안내

데이터를 수정하면 캐시 버전을 올려 모든 사용자가 최신 파일을 받게 하세요.
- `schedule.js` → `index.html` 의 `schedule.js?v=` 숫자
- `data/cN.js` → `index.html` 의 `DATA_VER` 값

# 정시 나침반 (`jeongsi.html`)

목표 수능 등급을 넣으면, **대학마다 다른 수능 반영 방법**(반영 영역·비율·활용지표·지정과목·영어/한국사 배점)을
그대로 적용해 지원 가능선을 살펴보는 정적 웹 도구입니다.

- 배포 주소: `https://maechorom31-pixel.github.io/najuhighexam/jeongsi.html`
- 자료: 2026학년도 정시 모집 자료 엑셀(2025년 12월 기준)
- 담긴 범위: 수능 위주 전형 **5,730개 모집단위**, 2025학년도 입시결과(50%·70%컷)·경쟁률·충원율

## 화면

| 탭 | 하는 일 |
|----|---------|
| 전체 탐색 | 권역·군·계열·판정·모집인원으로 좁혀 가며 모집단위 표를 살펴봅니다 |
| 수학 부담 낮은 곳 | 수학을 **미반영**하거나 **택N에서 뺄 수 있는** 모집단위만 모아 봅니다 |
| 잘 환산해 주는 대학 | 이 성적을 후하게 계산해 주는 대학을 **반영 유불리** 순으로 줄 세웁니다 |
| 관심 목록 | 담아 둔 모집단위를 **가·나·다군으로 정리**해 견주고, 인쇄하거나 PDF로 저장합니다 |

좁은 화면에서는 계열·기타·경쟁률 칸을 접고, 모집단위 이름 아래에 컷·판정·유불리를
붙여 가로로 밀지 않아도 가늠할 수 있게 했습니다. 담기 단추는 표 오른쪽에 고정되지만,
480px 아래에서는 고정을 풀어 학과 이름이 가려지지 않게 합니다.
인쇄하면 성적 입력 칸과 분포 그림은 빠지고 요약과 목록만 종이에 남습니다.

표에는 **국어·수학·영어·탐구·기타(한국사+제2외국어)** 다섯 칸으로 반영비율을 모두 펴 놓았습니다.
이 성적에 실제로 적용된 값이며, 다섯 칸을 더하면 100%가 됩니다.
`*`는 대학이 골라서 반영하는 영역이라는 뜻이고, `*`가 붙은 `–`는 더 잘한 영역이 대신 들어가 빠졌다는 표시입니다.
`–`만 있으면 그 대학이 아예 반영하지 않습니다. 각 행을 열면 대학이 정한 원래 배점(선택 영역의 1·2순위 배점 포함)도 함께 나옵니다.

넣은 성적과 담기 표시는 이 브라우저에 남으므로, 창을 닫았다 열어도 그대로입니다.
저장된 값이 망가져 있으면 기본값으로 되돌리고 화면은 그대로 뜹니다.
필터를 여럿 걸어 결과가 비면 **좁혀 둔 조건**을 짚어 주고, **조건 초기화** 단추로 한 번에 되돌립니다
(성적은 그대로 둡니다).
필터는 권역·군·계열·판정·수학 반영 정도에 더해 대학 이름, 모집단위 이름, **전형 이름**,
최소 모집인원, **2025 경쟁률 상한**, **반영 유불리**, **입시결과 신뢰도**,
지정과목 충족, 입시결과 유무, 관심 목록으로 좁힐 수 있습니다.

각 행을 누르면 먼저 **왜 이렇게 계산됐는지**를 문장으로 풀어 줍니다 —
어떤 영역을 반영하는지, 이 성적에서 어느 영역이 뽑히고 어느 영역이 빠졌는지,
수학 부담이 낮다면 그 이유가 무엇인지, 유불리가 어디서 왔는지.
이어서 실제 적용된 비율, 활용지표, 지정과목, 영어·한국사 배점, 전형,
가산점, 모집인원 추이, 경쟁률·충원율이 표로 붙습니다.

## 통계로 뒷받침한 지표

이 자료로 직접 확인한 사실을 근거로 삼았습니다.

**입시결과 신뢰도** — 2026 모집인원이 적을수록 최근 3개년 경쟁률이 크게 흔들립니다.
변동계수 중앙값이 1~2명 27.5%, 3~5명 18.8%, 6~10명 15.0%, 11~20명 13.2%,
21~50명 11.0%, 51명 이상 9.1%로 단조롭게 줄어듭니다. 이 폭에 맞춰 감점하고,
신설 여부·경쟁률 변동계수·전형/반영비율 변경·수시이월 비중·모집인원 증감·
반영비율 매칭 정확도를 합쳐 **안정 / 보통 / 주의** 세 단계로 나눕니다.
결과를 되짚어 보면 등급별 경쟁률 변동계수 중앙값이 안정 11.1%, 보통 20.5%,
주의 31.7%로 갈려, 지표가 실제 변동을 잘 가릅니다.
표에서는 모집인원 옆 세 칸 게이지로, 상세에서는 감점 사유로 보여 줍니다.

**실질경쟁률** — 충원율 중앙값이 94%이고 절반(49%)이 100%를 넘습니다.
모집인원만큼 추가합격이 도는 곳이 절반이라는 뜻이라, 겉경쟁률만 보면 문턱을
잘못 읽습니다. 표의 경쟁률 칸에 `8.6 (4.7)`처럼 실질경쟁률을 괄호로 함께 적습니다.

**군 이동** — 대학이 군을 옮기면 지원자 풀이 통째로 달라집니다.
한양대는 올해 가군 −305명, 나군 +325명입니다. 상세에 대학별 군 정원 증감을
싣고, 50명 이상 움직인 곳은 따로 알립니다.

**내 위치 지도** — 2025학년도 70%컷 백분위 분포를 5점 구간 막대로 그리고
기준 백분위 자리에 선을 세웁니다. 같은 대학 안에서도 학과 간 컷 폭이
중앙값 27점이라, 대학 이름만으로 판단하지 않도록 학과 단위 분포를 보여 줍니다.

## 계산 방법

1. **성적 확정** — 등급(+등급 내 상/중/하)을 2026 수능 실제 분포에 맞춰 백분위·표준점수로 바꿉니다.
   백분위를 직접 넣을 수도 있습니다.
2. **기준 백분위** — 원자료와 같은 축인 `국수탐(2) 백분위 평균 = AVERAGE(국어, 수학, AVERAGE(탐구1, 탐구2))`.
3. **가능성 판정** — 기준 백분위에서 그 모집단위의 **2025년 70%컷 백분위**를 뺀 값으로
   안정 / 적정 / 소신 / 도전 / 위험을 나눕니다. 컷 백분위는 대학이 공개한 값으로,
   원자료의 조견표가 쓰는 축과 같습니다.
4. **반영 유불리** — 모집단위의 반영영역 표기(`택2(국수영)+탐1한` 등)를 파싱해
   학생에게 가장 유리하도록 배점을 배정하고, 활용지표(표준점수/백분위/변환표준점수/등급)와
   영어·한국사 등급별 배점표를 적용해 환산점을 냅니다.
   그 점수를 **국·수·탐을 모두 같은 백분위로 받은 학생**과 견주어 백분위로 되돌린 뒤,
   기준 백분위와의 차이를 유불리로 표시합니다.

> 유불리를 가능성 판정에 더하지 않은 이유: 공개된 컷 자체가 이미 그 대학 방식으로 뽑은 결과라
> 그대로 더하면 이중으로 셈하게 됩니다. 유불리는 *같은 백분위대에서 앞설지 뒤질지*를 보는 눈금입니다.

## 한계

- 대학 고유의 세부 산식, 가산점 수식, 제2외국어 대체, 실기 반영은 그대로 옮기지 못했습니다.
- 반영비율 매칭은 5,730개 중 5,345개가 정확히 맞고, 나머지는 같은 대학의 다른 전형에서 끌어와
  맞췄거나(311개) 자료가 없습니다(74개). 상세 화면에 '확인 필요'로 표시됩니다.
  폴백으로 가져온 경우 **지정과목은 물려받지 않습니다** — 잘못 물려받으면 지원 가능한 곳이
  통째로 사라지기 때문입니다.
- 원자료의 반영비율 합계가 100%가 아닌 모집단위가 58개 있습니다(대학 표기 자체의 불일치).
  상세 화면에 오차가 크다고 표시됩니다.
- 실제 지원은 각 대학 모집요강과 대교협 대입상담프로그램으로 다시 확인해야 합니다.

## 자료 갱신

자료 엑셀의 새 판이 나오면 다시 변환합니다.

```bash
pip install openpyxl
python3 tools/build_jeongsi.py <자료.xlsx> data/jeongsi
```

`data/jeongsi/meta.json`(등급↔표준점수↔백분위 변환표, 대학별 변환표준점수표)과
`data/jeongsi/units.json`(모집단위 5,730행, 열 사전 압축)이 다시 만들어집니다.
같은 입력이면 같은 바이트가 나오므로, 새 자료로 바꿨을 때 무엇이 달라졌는지 diff로 볼 수 있습니다.
파일을 바꾼 뒤에는 `jeongsi-app.js`의 `?v=` 값을 올려 캐시를 넘기세요.

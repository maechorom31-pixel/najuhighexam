# 나주고 3학년 1반 기말고사 시간표 조회

**번호(1~19)** 를 입력하면 그 학생이 **응시하는 시험 과목만** 시간표로 정리해 주는 정적 웹페이지입니다.
이미지로 저장하거나 인쇄(PDF)할 수 있습니다.

> 2026학년도 1학기 기말고사 · 나주고등학교 3학년 1반(학번 3101~3119) 기준

## 사용법

`index.html` 을 브라우저로 열고 번호(예: `5`)를 입력하면 됩니다.
학번 앞자리 **31** 은 고정이라, 뒤 번호만 입력합니다.

- **이미지 저장**: 시간표 카드를 PNG 파일로 내려받기
- **인쇄 / PDF**: 브라우저 인쇄 기능으로 출력 또는 PDF 저장
- 딥링크: `?num=5` 또는 `?sid=3105` 로 바로 결과를 열 수 있습니다.

이 저장소는 GitHub Actions로 **자동 배포**됩니다(`.github/workflows/deploy-pages.yml`).

## 구성

| 파일 | 설명 |
|------|------|
| `index.html` | 화면·조회 로직 (번호 입력 → 개인 시간표 렌더) |
| `schedule.js` | 기말고사 시간표 + 과목 분류(일반선택/진로선택) |
| `roster.js` | 명단(번호별 선택과목) 데이터 — **Base64 인코딩**, 이름 없이 학번만 |

## 데이터 규칙

- **공통 과목**(화법과 작문, 영어독해와 작문)은 전체 학생이 응시합니다.
- **선택 과목**은 수강한 경우에만 응시하고, 아니면 그 시간은 **자율학습**(시험 없음)입니다.
- 배지는 교육과정 분류를 따릅니다.
  - **일반선택**: 화법과 작문, 영어독해와 작문, 미적분, 윤리와 사상, 한국지리, 사회문화
  - **진로선택**: 경제수학, 기하, 수학과제 탐구, 심화국어, 영미 문학 읽기, 화학Ⅱ, 생명과학Ⅱ, 물리Ⅱ, 지구과학Ⅱ, 일본어2, 프로그래밍
- 지필고사가 없는 선택과목(사회문제탐구·생활과 과학·교육학·논술·보건 등)은 시간표에서 제외했습니다.

## 데이터 / 개인정보

- 명단은 **이름 없이 학번만** 사용하며, `roster.js` 에 **Base64로 인코딩**되어 평문 노출을 줄였습니다.
  (정적 페이지 특성상 완전한 비공개는 아니며, 한 번의 복호화 경로를 거쳐 로드됩니다.)
- 시간표가 바뀌면 `schedule.js`, 명단이 바뀌면 `roster.js` 를 갱신하세요.

## 캐시 안내

`index.html` 의 스크립트 태그에는 `?v=` 버전 쿼리가 붙어 있습니다.
데이터를 수정하면 이 숫자를 올려서(예: `?v=4` → `?v=5`) 모든 사용자가 최신 파일을 받도록 하세요.

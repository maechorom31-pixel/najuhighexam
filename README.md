# 나주고 3학년 기말고사 시간표 조회

학번을 입력하면 **내가 보는 시험 과목만** 시간표로 정리해 주는 정적 웹페이지입니다.
이미지로 저장하거나 인쇄(PDF)할 수 있습니다.

> 2026학년도 1학기 기말고사 · 나주고등학교 3학년 기준

## 사용법

`index.html` 을 브라우저로 열고 학번 4자리(예: `3201`)를 입력하면 됩니다.

- **이미지 저장**: 시간표 카드를 PNG 파일로 내려받기
- **인쇄 / PDF**: 브라우저 인쇄 기능으로 출력 또는 PDF 저장
- URL 뒤에 `?sid=3201` 처럼 학번을 붙이면 바로 결과가 열립니다.

### 웹으로 배포하려면 (GitHub Pages)

저장소 **Settings → Pages**에서 브랜치를 지정하면 누구나 접속할 수 있는
주소로 공개됩니다. 별도 서버 없이 동작합니다.

## 구성

| 파일 | 설명 |
|------|------|
| `index.html` | 화면·조회 로직 (학번 입력 → 개인 시간표 렌더) |
| `schedule.js` | 기말고사 시간표 (날짜·교시·시간·과목, 공통/선택 구분) |
| `students.js` | 학번별 선택과목 데이터 **(이름 제외, 학번만)** |

## 데이터 규칙

- **공통 과목**(화법과 작문, 영어독해와 작문)은 전체 학생이 응시합니다.
- **선택 과목**은 학생이 수강 신청한 경우에만 응시하고, 아니면 그 시간은 **자율학습**(시험 없음)입니다.
- 지필고사가 없는 선택과목(사회문제탐구·생활과 과학·교육학·논술·보건 등)은 시간표에서 제외했습니다.

## 데이터 수정

시간표가 바뀌면 `schedule.js`, 수강 정보가 바뀌면 `students.js` 를 수정하세요.
`students.js` 형식:

```js
const STUDENTS = {
  "3201": ["경제수학", "윤리와 사상", "수학과제 탐구", "심화국어", "일본어2", "사회문화"],
  // 학번: [그 학생이 응시하는 선택과목 목록]
};
```

> 개인정보 보호를 위해 이름은 저장하지 않으며 학번만 사용합니다.

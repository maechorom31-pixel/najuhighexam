# 나주고 3학년 기말고사 시간표 조회

**반(1~6)을 고르고 번호를 입력**하면 그 학생이 **응시하는 시험 과목만** 시간표로 정리해 주는 정적 웹페이지입니다.
이미지로 저장하거나 인쇄(PDF)할 수 있습니다.

> 2026학년도 1학기 기말고사 · 나주고등학교 3학년 기준

## 사용법

`index.html` 을 열면 **반 선택 화면**이 나옵니다. 반을 고른 뒤, 학번 앞 두 자리(예: `32`)는 고정이므로 **뒤 번호만** 입력합니다.

- **이미지 저장**: 시간표 카드를 PNG 파일로 내려받기
- **인쇄 / PDF**: 브라우저 인쇄 기능으로 출력 또는 PDF 저장

### 반별 주소 (배부용)

각 반은 **무작위 토큰** 주소를 씁니다. 링크만 보고는 몇 반인지 알 수 없고,
토큰을 바꿔 다른 반에 접근할 수도 없습니다. 반 학생들에게 해당 링크를 나눠 주세요.

| 반 | 주소 |
|----|------|
| 반 선택(허브) | `…/najuhighexam/` |
| 1반 | `…/najuhighexam/?k=566f8cb7` |
| 2반 | `…/najuhighexam/?k=f980d51e` |
| 3반 | `…/najuhighexam/?k=1fe051a1` |
| 4반 | `…/najuhighexam/?k=041ce67a` |
| 5반 | `…/najuhighexam/?k=4f428556` |
| 6반 | `…/najuhighexam/?k=85f010ac` |

- 특정 학생 바로 열기: `?k=f980d51e&num=5`
- 배포 주소: `https://maechorom31-pixel.github.io/najuhighexam/`
- `?k=` 토큰이 없거나 잘못되면 어떤 반도 열리지 않고 **반 선택 화면**이 표시됩니다.

> **참고(정적 사이트 한계)**: 토큰↔반 매핑은 `index.html`/허브 화면에 들어 있어
> 소스를 열어보면 확인은 가능합니다. 즉 "링크만으로는 추측 불가"이지만 완전한 비공개는 아닙니다.
> 매핑이 드러나는 게 싫으면 **허브(루트 주소)는 공유하지 말고** 반별 토큰 링크만 배부하세요.

## 구성

| 파일 | 설명 |
|------|------|
| `index.html` | 반 선택 + 번호 입력 + 개인 시간표 렌더 |
| `schedule.js` | 기말고사 시간표 + 과목 분류(일반선택/진로선택) |
| `data/<토큰>.js` (6개) | 반별 명단(번호별 선택과목) — 파일명도 무작위 토큰, **Base64 인코딩**, 이름 없이 학번만 |

해당 반 주소로 들어올 때 **그 반의 데이터 파일만** 로드됩니다.

## 데이터 규칙

- **공통 과목**(화법과 작문, 영어독해와 작문)은 전체 학생이 응시합니다.
- **선택 과목**은 수강한 경우에만 응시하고, 아니면 그 시간은 **자율학습**(시험 없음)입니다.
- 배지는 교육과정 분류를 따릅니다.
  - **일반선택**: 화법과 작문, 영어독해와 작문, 미적분, 윤리와 사상, 한국지리, 사회문화
  - **진로선택**: 경제수학, 기하, 수학과제 탐구, 심화국어, 영미 문학 읽기, 화학Ⅱ, 생명과학Ⅱ, 물리Ⅱ, 지구과학Ⅱ, 일본어2, 프로그래밍
- 지필고사가 없는 선택과목(사회문제탐구·생활과 과학·교육학·논술·보건 등)은 시간표에서 제외했습니다.

## 데이터 / 개인정보

- 명단은 **이름 없이 학번만** 사용하며, `data/cN.js` 에 **Base64로 인코딩**되어 평문 노출을 줄였습니다.
  (정적 페이지 특성상 완전한 비공개는 아니며, 한 번의 복호화 경로를 거쳐 로드됩니다.)
- 시간표가 바뀌면 `schedule.js`, 명단이 바뀌면 해당 반 `data/cN.js` 를 갱신하세요.

## 캐시 안내

데이터를 수정하면 캐시 버전을 올려 모든 사용자가 최신 파일을 받게 하세요.
- `schedule.js` → `index.html` 의 `schedule.js?v=` 숫자
- `data/cN.js` → `index.html` 의 `DATA_VER` 값
